📝 임용쏙이란?

중등교사 임용시험을 준비하는 수험생을 위한 AI 기출 유사 문제풀이 도구입니다. 가정 전공과 사서 전공(문헌정보학), 그리고 두 전공이 공통으로 치르는 교육학을 지원합니다. 2016~2026학년도 기출 경향을 반영해 실제 시험과 동일한 형식으로 출제하고, 실제 채점 기준으로 점수를 매깁니다.

과목 선택에서 「가정/사서 전공 + 교육학 랜덤」을 고르면 본인 전공과 교육학이 실제 시험 비중대로 섞여 나옵니다. 사서 전공은 자료조직·정보서비스·정보검색·도서관경영·독서교육·정보활용교육·학교도서관법규·서지학 8개 영역을 다룹니다.

🚀 사용 방법

  1. 우측 상단 ⚙️ 설정에서 AI API 키 등록 (Claude 권장)
  2. 과목·유형·영역을 고르고 🎲 문제 출제 — 랜덤으로 두면 실제 시험 비중대로 섞여 나옵니다
  3. 권장 시간(기입형 2분 / 서술형 7분 / 논술 60분) 안에 답안 작성 후 ✅ 채점하기
  4. 점수·채점 기준표·모범답안·해설·키포인트·자주 하는 실수까지 즉시 확인
  5. 감점된 문항은 📕 오답노트에 자동 저장 — 같은 주제로 유사 문제 재출제 가능
  6. 📊 학습통계에서 영역별 득점률을 보고 약한 영역을 집중 공략

📰 교육 트렌드 자동 반영

실제 교육학 논술은 항상 최신 교육 정책·이슈(AI 디지털교과서, 고교학점제, 2028 대입개편 등)를 제시문 맥락으로 활용합니다. 임용쏙은 최신 교육 동향 데이터를 내장하고 있으며, 「📰 교육 트렌드」 탭에서 🔄 AI 웹검색으로 갱신을 누르면 Claude·Gemini의 실시간 웹검색으로 최신 뉴스·정책·새 교육과정 비전을 가져와 교육학·가정과 교육론 출제에 자동 반영합니다. 2주에 한 번 정도 갱신하는 것을 권장합니다.
